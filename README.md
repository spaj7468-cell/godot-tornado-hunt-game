# Tornado Hunt Game

Небольшой прототип на Godot 4.x: стартовое меню, тестовая 3D-сцена, базовое управление персонажем и простые элементы HUD. Проект развивается отдельно от основных продуктов OuRi.

## Что сейчас есть
- Стартовое меню с запуском игры, настройками и выходом.
- Настройки громкости главной аудиошины и полноэкранного режима.
- Тестовая 3D-сцена с освещением, землёй, персонажем и камерой.
- Базовое перемещение персонажа клавишами направления Godot (по умолчанию — стрелки).
- Кнопка карты показывает текущие координаты персонажа.
- Кнопка радара показывает статус прототипа.

## Что пока является заглушкой
- Живое обнаружение торнадо на радаре.
- Полноценная карта, система погоды, экономика и прогрессия.
- Машины, миссии, сохранения и игровые режимы.

Наличие элемента интерфейса не означает, что соответствующая игровая система уже реализована. Список выше разделяет работающие элементы и будущие функции.

## Запуск
1. Установи Godot 4.x.
2. Клонируй репозиторий или скачай его архив.
3. Открой project.godot в Godot.
4. Нажми F5, чтобы запустить основную сцену.

## Управление
- Стрелки — перемещение тестового персонажа.
- SETTINGS — громкость и полноэкранный режим.
- MAP — показать координаты персонажа.
- RADAR — посмотреть статус прототипа радара.
